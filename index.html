Groups and classes
Name a group whatever you like, then tell it which class it counts as. That is what builds the code: Select Choir wins over everything, both halves of a grade give 6AB or 7AB, and a group set to "no class" contributes nothing.
Import names
Paste a plain list, one person per line, in the form Last name, First name. Anyone already on the roster is skipped rather than given a second code — but they still join the groups you tick, which can change their code. The preview shows exactly that before anything is saved.

Choose who gets a barcode
Pick the students you need cards for. Sheets are sized for Avery 5162 — 4″ × 1⅓″, 14 to a page. Anyone without a class has no code and can't be printed.
Print the sheet
Position 1 is the top-left label, 2 is top-right, 3 starts the second row. Bump it up if you're reusing a partly-peeled sheet. The nudge fields shift everything a hair if your printer runs off-centre — worth a test print on plain paper held against a label sheet the first time.
In the print dialog set Scale: 100% (or "Actual size") and Margins: None, or the labels will drift off the sticker grid.
Renumber a class
Taking people out of a class leaves gaps in its numbering. Renumbering closes them so the class runs 1 to N again — but it moves numbers between students, so only do it when you're ready to reprint and hand out that whole class's cards. Anyone whose number doesn't move keeps the card they already have.
